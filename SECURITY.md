# Security Policy

## Scope

The latest revision on the default branch is the only supported version of this
reference implementation. The repository is educational and carries no production
security guarantee.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, personal data, or
private system information.

Use GitHub's private vulnerability reporting entry for this repository when it is
available. If that entry is unavailable, contact the maintainer through the GitHub
profile and request a private channel without including vulnerability details in the
initial message.

Include only synthetic reproduction data and provide:

- the affected revision and component;
- expected and observed behavior;
- minimal reproduction steps;
- impact and preconditions;
- a proposed mitigation, if known.

Never send a live credential or real person's data. Reports will be acknowledged and
triaged on a best-effort basis; no response-time or remediation SLA is promised.

## Disclosure

Please allow time for validation and remediation before publishing details. A fix may
include tests, documentation, and a security advisory. Public credit is optional and
will be agreed with the reporter.
